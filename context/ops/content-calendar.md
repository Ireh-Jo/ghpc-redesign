## 4. 이벤트가 생길 때마다 (어드민 전까지)

어드민이 생기면 이 표는 통째로 "어드민에서"가 된다 (`docs/어드민-착수-플랜.md` §3 · §7).

| 영역 | 파일 | 비고 |
|---|---|---|
| 메인 중앙 배너 | `lib/main-banners.ts` + `public/banners/` | 원본 3.2:1 · 화면 3.6:1 — 위아래 6% 안쪽에 글자 (`context/components/content/main-banner.md`) |
| 공지사항 (메인 4줄) | `lib/notices.ts` | 매주 바뀔 수 있다 — 어드민 1순위 |
| 신앙 간증 영상 | `lib/worship-videos.ts` (`testimony`) | 유튜브 재생목록이 없어 **유일하게 손으로** 추가하는 영상 분류 |
| 금요밤기도회 강해 재생목록 | `lib/worship-archive.ts` (`PLAYLISTS.exposition`) | **강해 시리즈가 바뀌면** 새 재생목록 ID로 교체 (갈라디아서 → 하박국 → …) |

## 5. 자동이라 손댈 필요 없는 것 (참고)

예배 실황 · 특송 · 구역공과 · 경향의 일주일 영상 → 유튜브 재생목록 RSS로 자동 (`lib/worship-archive.ts`, 10분 캐시).
생방송 → 채널 라이브 자동 감지 (`lib/youtube-live.ts`). 단 **유튜브 제목·설명란 양식이 바뀌면** 파싱이 깨질 수 있다
(제목의 `YYYY-MM-DD` · 설명란 `설교:` 줄) — 미디어팀에 양식 유지를 부탁해 둘 것.
