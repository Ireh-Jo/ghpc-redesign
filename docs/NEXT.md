### 1-3. `/ministry` 기관 페이지 템플릿 확정 (구 Phase 1-1)

`OrgSection`(기관 소개 공통 블록: 로고·한 줄 소개·활동사진 4·외부 링크)을 만들어 6기관에 적용.

(순서를 뒤집으면 몇 주 손실). 외부 링크 URL은 작업플랜 §1에 확보돼 있음.

### 1-4. 게시판형 라우트 목록 UI (주보·공지·소식 4종·자료실)

## 3. 🔴 착수 금지 (결론 없이 손대면 안 되는 것)

1. **보안지역(특수지역) 선교사 지도** — 실명·파송국가·사진 공개는 선교사 안전 문제. 선교회 담당자 확인 전
   `/ministry#mission` 지도 위젯 착수 금지. (작업플랜 §2 B-2 · 디자이너 가이드 Phase 3에도 보류로 명시함)
2. **새가족 수료자 실명 명단** — 공개 웹 게시는 개인정보 이슈. 어드민 내부 또는 "N명"만 노출 권고. (§2 B-1)
   `lib/nav.ts`의 `UNPLACED`에 유일하게 남아 있는 항목.
3. **RLS 미설계 테이블에 운영 데이터 투입** — `guardrails/04-security-privacy.md`.
   폼 4종의 Server Action은 환경변수가 없으면 **성공으로 위장하지 않고** 접수 불가를 반환하도록 돼 있다. 그대로 둘 것.
