## 4. 결정 기록 (2026-09-16 · 사용자 확정)

### 4-1. 전역 라운드 전환
F안 임시 룩의 직각(`.btn-square` 2px)을 폐기하고 **전역 라운드**로 갔다. `.btn-round`(10px)로 이름까지 바꿔
기존 18곳이 한 번에 따라오게 했다. 결과적으로 원래 `context/design/03-spacing.md`가 정의하던 라운드 체계로 복귀한 것.
서브페이지(예배 표·영상 카드·플로어맵 컨트롤)도 같이 둥글어졌다.

### 4-2. 시안에 없는 F안 섹션 3종은 내린다
공동체 가치 3 · 표어 배너(`CampaignBanner`) · LIVE+오시는 길 2컬럼. 컴포넌트 파일은 서브페이지 재사용분이라 남겼다.

### 4-3. 푸터는 이번 범위 밖
시안 푸터(관련기관 버튼 6 · SNS 4 · 교회 실루엣 · 회색 하단바)는 전역 컴포넌트라 서브페이지 전체에 영향 간다.
헤더 생방송 CTA 유지 여부(9/15부터 디자인팀 회신 대기)와 **묶어서 한 번에** 교체한다.

### 4-4. 관리자 영역은 배너 · 공지 둘
`lib/main-banners.ts` · `lib/notices.ts`가 지금의 단일 출처다. 두 컴포넌트 모두 **배열만 받는 구조**라
Supabase + 어드민이 붙으면 데이터 출처만 갈아끼우면 된다 (`context/features/admin-ui.md`).

## 5. 디자인팀 회신 요청

1. **모바일 배너 크롭** — 시안 모바일 배너는 2줄로 다시 조판돼 있다. PC용(3.2:1)만 받아서 지금은
   16:9로 가운데를 잘라 쓰는 중이라 양 끝 그래픽이 잘린다. 750×780 내외의 모바일 크롭을 주면
   `lib/main-banners.ts`의 `srcMobile`에 바로 꽂는다.
2. **메인 헤로 영상 2종** (PC 가로 / 모바일 세로) — Phase 1 요청분. 지금은 임시 영상·임시 사진이다.
3. **헤더 생방송 CTA** 유지 여부 (9/15부터 대기) — 시안 헤더에는 없다. 없애면 `Header`에서 한 줄 제거.
4. **푸터 시안 적용 시점** — 관련기관 로고/링크 6종, SNS 4종(blog·facebook·cafe·youtube) 실제 URL 필요.

## 6. 사용자·교회 판단 대기

1. **퀵메뉴 `구역공과` 목적지** — 2차 목차에 없는 항목이라 잠정으로 `/church-admin/resources`(자료실)로 보냈다.
   `lib/nav.ts`의 `OPEN_QUESTIONS`(게시 여부·대상)와 같은 건이다.
2. **공지 4건의 실제 링크** — 지금은 전부 목록 스텁으로 간다. 게시판형 목록 UI(`docs/NEXT.md` 1-4) 이후 글 URL로.

### 2차 보강 (같은 날 · 사용자 피드백)

"만들고 나니 텅 비어 보인다 / 사랑의교회처럼 색 채우기·카드 뒤집기 효과를 넣어 달라"에 대한 처리.

| 지점 | 보강 |
|---|---|
| **관련 기관 6칸 신설** | 시안에선 푸터 안 블록이었는데 푸터를 안 건드리기로 해서 **새가족 아래 페이지 섹션**으로 뺐다. `components/content/related-orgs.tsx` + `lib/related-orgs.ts`. URL은 작업플랜 §유형 A에서 확보된 값 (2곳은 미확인 → `/ministry` 앵커) |
| **새가족 카드** | 라벨+아이콘뿐이라 비어 보였다 → 안내 문구 2줄 + 바로가기 칩 3개 + 주 버튼 + 배경 장식 아이콘. 좌측에도 리드 문단 추가. 폼이 1차 범위 밖이라 버튼 문구는 "새가족 안내 보기" |
| **퀵메뉴** | 라벨 아래 설명 한 줄(`QUICK_MENU[].desc`) 추가 — 타일 4개만 떠 있던 여백이 줄었다 |
| **색 채우기** | 퀵메뉴 타일(아래→위 ink) · 새가족 칩(좌→우 흰색) · 공지 행 밑선(좌→우 accent) |
| **카드 뒤집기** | 관련 기관 6칸에만 (`rotateX` 500ms). 앞면 기관명 / 뒷면 소개 + 바로가기 |
| **밑줄 와이프** | `.link-wipe` 유틸 신설 (사랑의교회 `a.hover::before` 패턴) — 텍스트 링크에 적용 |

뒤집기·채우기는 전부 `prefers-reduced-motion`에서 꺼진다. 뒤집기는 **hover 없는 터치 환경에서 앞면만 보이므로**
뒷면에는 보조 정보만 둔다는 원칙을 `06-motion.md`에 같이 적어 뒀다.

### 모션 (`context/design/06-motion.md`에 추가 등재)

스크롤 진입 페이드업(stagger) · 카드 호버 리프트 + 그림자 · 썸네일 호버 줌 · 목록 행 화살표 슬라이드인 ·
수동 캐러셀 500ms · **색 채우기 · 밑줄 와이프 · 카드 뒤집기**(2차 보강).
전부 `motion-reduce`에서 꺼진다. 자동재생·패럴랙스는 그대로 금지.
