## 1. 시안이 정한 것 (그대로 따름)

- 상단 배너 + 앵커바(주일학교 / 중고등부 / 대학부 / 청년회 / 경향시니어스쿨 / 평생교육원 / 새소식반)
- 부서 섹션 머리: `01 SUNDAY SCHOOL`(번호+영문) → 큰 제목 → 한 줄 리드 → 오른쪽 파란 카페 버튼 → 구분선
- **소개 카드**: 연한 네이비 틴트 박스, 좌측 `01 주일학교 소개` + 본문 / 우측 활동사진 4슬롯
- 부서 카드: 그룹 제목(미취학부·초등부) + 카드 4열 (이름 / 연령·시간 / 장소)
- 히어로 문구: 아이브로우 `— 예배와 교육 - 교육` · 제목 `교육` · 리드 `영아부터 어르신까지, 한 말씀 위에서 자라는 사람들`

| 영역 | 처리 | 근거 |

## 3. 구조 결정 — `SubPage`를 쓰지 않았다

`SubPage`는 **"대메뉴 = 라우트"** 를 가정한다 (`sectionKey`의 앵커만 모음). 교육은 `예배와 교육` 대메뉴의
**하위 그룹**이라 앵커는 `/education#*`인데 섹션 href는 `/worship`이어서 그 가정에 안 맞는다.
그래서 `HeroImage` + `AnchorNav` + 섹션을 직접 조립했다 — 우회 로직이 없어 오히려 단순하다.

**주의:** 앵커 id·순서는 `lib/nav.ts` 교육 그룹과 1:1이어야 한다. GNB가 그 id로 들어온다.

## 4. 예배 페이지에서 교육 영역 제거

`/worship` 하단의 "교육" 바로가기 카드 7개를 내렸다 (사용자 지시). `SubPage`에 `hideOutboundGroups` 옵션을 추가해
그룹 라벨로 숨긴다. **GNB의 교육 링크는 그대로** `/education#*`으로 간다.
