# 현행 사이트(ghpc.or.kr) 메뉴 전수 분석 — 미배치 항목 해소

> 조사일 **2026-08-23** · 조사 방법: 현행 사이트 GNB·사이트맵 DOM 전수 크롤 + 각 하위 페이지 본문 확인
> 목적: `lib/nav-v2.ts`의 `UNPLACED` 4건(집사회·권사회 / e교회행정 하위 / 교구친선리그 / 새가족 수료자 명단) 중
> **회신 없이도 사실 확인만으로 풀 수 있는 3건**을 현행 콘텐츠 실체에 근거해 배치한다.

## 0. 조사에서 먼저 확인된 사실

1. **e교회행정 전 항목은 로그인 없이 공개된다.** 회원제·인증 영역이 아니다 (10개 하위 URL 전부 200 + 로그인 리다이렉트 없음).
   → 개편 후에도 "회원 전용 영역"을 새로 만들 필요가 없다. 이 메뉴는 **권한 문제가 아니라 대상 문제**다
   (교인·기관 임원용 실무 도구가 대메뉴 6개 중 하나를 차지하고 있었음).
2. **e교회행정의 `교회,교단일정`은 구글 캘린더 iframe 한 장**이다. 2차 목차의 `교회 활동 > 교회 일정`과 같은 물건이라
   이관이 아니라 **중복 해소**다.
3. **`시설이용신청`은 캡차 달린 신청 폼(게시판형)** — `context/features/reservation.md` 예약시스템의 현행 대응물이 맞다.
4. **집사회(192명)·권사회(470명)는 남/여전도회와 같은 층위의 조직 소개 페이지**다. 설립목적 / 역할·활동 / 활동사진의
   동일 3단 구성 — 남전도회·여전도회와 템플릿이 같다. 별도 취급할 이유가 없다.
5. **교구친선리그는 풋살 경기 영상 게시판**(2019~2026 누적, 제17회). 소식이 아니라 **영상 아카이브**다.

## 2. 배치 결론 (기본값 · 이의 없으면 확정)

### 2-1. 집사회 · 권사회 → `목양과 사역 > 기관` 그룹 신설

현행 `연합기관`(남전도회·여전도회·청년회·집사회·권사회·후원회)은 2차 목차에서 해체돼
전도회→목양, 청년회→교육, 후원회→사역으로 흩어졌고 **집사회·권사회만 갈 곳이 없었다.**
개별 항목으로 목양 그룹에 밀어넣으면 목양이 7항목이 되어 메가메뉴 열 균형이 깨진다.

→ `목양과 사역`의 L2 그룹을 2개(목양/사역)에서 **3개(목양 / 기관 / 사역)** 로 늘리고,
`기관` = 남전도회 · 여전도회 · 집사회 · 권사회로 묶는다. 현행 `연합기관`의 실체를 대부분 복원하는 셈이라
기존 교인의 학습된 위치 감각도 유지된다.

- `전도회` 단일 항목 → **남전도회 / 여전도회로 분리.** 현행 콘텐츠가 각각 독립 페이지이고
  활동(기드온찬양대 / 한나·루디아찬양대)도 별개다. 합쳐 쓸 근거가 없었다.
- 앵커: `/care#men` `/care#women` `/care#deacons` `/care#kwonsa` — L3 상한 준수, 한 페이지 안 앵커.

> DECISION NEEDED: **청년회 소속.** 현행은 연합기관, 2차 목차 PPT는 교육 밑(`lib/nav-v2.ts`에 "소속 미정" 주석).
> 위 `기관` 그룹이 생기면서 청년회를 여기로 되돌릴 자리가 생겼다. **교회에 물을 사실 질문**이지 디자인 판단이 아님.

### 2-2. e교회행정 → `교회소개 > 교회정보`의 한 줄 (`/church-admin` 허브)

> **2026-08-23 정정.** 처음엔 `교회 활동 > 행정·신청` 그룹으로 뒀으나, 2차 개편안 PPT 슬라이드 4가
> `교회정보: 교회 위치, 교회 시설, 전화번호, 온라인 헌금, 교회 일정, **e행정**`으로 적어둔 것을 확인하고
> 원안 위치로 되돌렸다. 아래 이관 표의 행선지는 전부 `/church-admin` 아래로 읽는다.

대메뉴 5개 유지 결정(2026-08-10)을 지키면서 6번째 대메뉴의 내용물을 잃지 않는 배치.

| 시설이용신청 (+ 키즈그라운드) | `e교회행정 > 시설 예약` (`/church-admin/reserve`) | 예약시스템 진입점. `context/features/reservation.md` |
| 영상제작신청 / 3대 후원회원 작정 / 평생교육원신청 | `e교회행정 > 신청·서식` (`/church-admin/apply`) 한 페이지 + 앵커 3 | 셋 다 단순 폼. GNB에 폼 3개를 나열할 가치 없음 |

`교회 활동` tagline은 "이번 주 경향교회" 유지. 행정·신청은 세 번째 열로만 붙어 톤을 깨지 않는다.

**대안(폐기)**: `교회소개 > 교회정보`에 붙이기 — 교회소개는 외부인 대상 정적 소개 성격이라
교인 실무 도구가 섞이면 새신자 동선이 흐려진다. 헤더 유틸리티 영역 분리안도 대메뉴 외 2차 내비를
새로 만드는 비용 대비 이득이 없어 폐기.

### 2-3. 교구친선리그 → `교회 활동 > 소식·자료 > 영상뉴스` 안 탭

`교회소식`(`/activity/news`)은 PPT 슬라이드 7이 하위 3종(영상뉴스·교회소식·교우소식)을 거느린 한 줄로 적어둔 항목이다.
교구친선리그도 같은 영상 아카이브라 여기 탭으로 붙인다. GNB 항목은 늘리지 않는다.
(`경향의 일주일`은 2차 목차에서 이미 독립 라우트로 승격돼 있으므로 그대로 둔다.)

### 2-4. 미해소 — `새가족 수료자 명단`

실명 공개 개인정보 이슈(작업플랜 §2 B-1). 사실 조사로 풀리는 문제가 아니므로 `UNPLACED` 유지.

- `/activity` 하위 독립 라우트 목록이 확정 가능해졌다 (2026-07-01 결정의 `DECISION NEEDED` 일부 해소):
