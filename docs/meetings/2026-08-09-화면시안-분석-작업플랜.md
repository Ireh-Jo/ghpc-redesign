## 2. 즉시 차단 이슈 (개발 전 결론 필요)

### 🔴 B-1. 수료자 실명 명단 공개

`새가족등록, 새가족모임.html` 하단에 **날짜 + 실명**을 입력해 공개 목록으로 렌더하는 UI가 있다
(현재는 `localStorage` 데모).

- 새가족 실명을 공개 웹에 게시 → 개인정보 수집·제3자 열람 이슈
- `guardrails/04-security-privacy.md` 및 새가족 폼 동의 문구와 충돌
- 실무상으로도 "누가 새가족인지"가 공개되는 건 당사자가 원치 않을 수 있음

**권고:** 공개 페이지에서 제외. 필요하면 어드민 내부 화면으로만. 또는 이름 없이 "이번 달 수료 N명"만 노출.
→ **교회 확인 필요.**

### 🔴 B-2. 보안지역(특수지역) 선교사 정보 노출

`사역(3대 후원회).html`의 선교사 지도에 지역 구분이 **러시아 / 아시아 / 남미 / 특수지역**으로 되어 있고,
"선교사 이름을 클릭하면 사역 정보를 볼 수 있습니다"라고 안내한다.

창의적 접근지역(특수지역) 선교사의 **실명·파송국가·사진**을 공개 웹에 노출하는 것은
선교사 본인과 현지 사역의 안전 문제로 직결된다. 통상 이런 지역은 이니셜·가명·지역 비공개로 처리한다.

**권고:** 지역별 인원 수만 표시, 특수지역은 이름·국가 비공개. **선교회 담당자 확인 필수.**
