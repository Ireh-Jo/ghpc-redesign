> 받는 분: 박정민 집사님 · 장진경 집사님
> 보내는 사람: 이레 · 2026-08-23
> **Figma·웹플로우 필요 없습니다.** 일러스트레이터·포토샵으로 만드신 파일을 그대로 주시면 제가 웹에 넣습니다.

## 0. 지금 어디까지 왔나

메뉴 구조(어떤 메뉴 아래 어떤 페이지가 들어가는지)와 화면 골격이 **다 잡혔습니다.**
지금 화면은 글자만 있고 사진·로고 자리는 비어 있거나 임시 스톡 사진(무료 사진 사이트)이 들어가 있습니다.
그래서 지금부터는 **비주얼 자산**이 들어와야 다음 단계로 넘어갑니다.

역할은 5월에 정한 대로입니다.

| 하는 일 | 담당 |
|---|---|
| 메뉴 구조 · 화면 설계 · 개발 | 이레 |
| **사진 · 로고 · 일러스트 · 아이콘 제작** | **박정민 · 장진경** |
| 화면 보고 피드백 | 박정민 · 장진경 |

아래 Phase 1 → 4 순서대로 요청드립니다. **Phase 1이 제일 급합니다** — 이게 없으면 나머지 화면을 확정할 수 없습니다.

## 공통 전달 규칙

| 종류 | 형식 | 규격 |
|---|---|---|
| 사진 | JPG | 가로 2000px 이상, 보정 완료본 |
| 로고 · 아이콘 · 일러스트 | **SVG 우선**, 어려우면 PNG | PNG는 배경 투명 + 2배 크기 |
| 영상 | MP4 | 아래 Phase 1 참고 |

- 파일명: `{페이지}-{용도}-{번호}` — 예: `main-hero-01.jpg`, `intro-history-03.jpg`
- **전달 경로: 구글드라이브**로 하겠습니다. 폴더 링크는 아래 '확인 방법'의 사이트 주소와 함께 보내드립니다.

### 색

홈페이지에 쓰고 있는 색입니다. 로고·아이콘 작업할 때 이 값을 그대로 써주세요.

| 쓰임 | 색 | 값 |
|---|---|---|
| 바탕 (전체 배경) | 따뜻한 아이보리 | `#FAF9F7` |
| 글자 · 어두운 배경 | 먹색 | `#141210` |
| 강조 1 (링크·버튼) | 파랑 | `#002D60` |
| 강조 2 (생방송·새가족) | 초록 | `#00634A` |
| 포인트 (경고·필수 표시) | 빨강 | `#A00711` |

새 색을 쓰고 싶으시면 미리 말씀해주세요. 파랑·초록·빨강은 7월 2일에 확정한 값이라 바꾸려면 화면 전체를 함께 봐야 합니다.

### 사진 고를 때 지켜야 할 것 (전 Phase 공통)

1. **얼굴이 또렷하게 식별되는 사진은 피해주세요.** 뒷모습·실루엣·손·측면·멀리서 찍은 것이 안전합니다.
   (교인 사진을 홈페이지에 올리려면 본인 동의가 필요합니다. 동의를 받은 사진이면 알려주세요 — 그건 써도 됩니다.)
2. 어린이·청소년 사진은 특히 조심해주세요. 얼굴이 나오면 보호자 동의가 따로 필요합니다.
3. 밝고 따뜻한 톤 (역광·햇살·나무·천 같은 질감). 어둡고 차가운 톤은 메인 첫 화면에만 씁니다.
4. 가로로 넓은 사진이 쓰기 좋습니다. 인물이 정중앙에 딱 있으면 잘릴 수 있으니 여백을 넉넉히.

## Phase 1 — 브랜드 기본 (제일 급함 · **8월 30일까지**)

이게 없으면 모든 화면의 첫인상이 확정되지 않습니다. 지금은 예전 로고 이미지 파일(`logo.png`)로 버티는 중입니다.

### 1-1. 로고

> **새로 그리실 필요 없습니다.** 현재 홈페이지 `e교회행정 > 자료실 > 로고` 페이지에
> 경향교회 로고와 마크가 **AI 원본으로 이미 올라가 있습니다.** 그 파일을 열어서
> 아래 3종으로 정리해 SVG로 내보내 주시면 됩니다.
> 주소: https://www.ghpc.or.kr/Page/Index/9758

| 파일 | 용도 | 형식 |
|---|---|---|
| 가로형 로고 — **어두운 배경용**(흰 글자) | 메인 첫 화면 상단, 푸터 | SVG |
| 가로형 로고 — **밝은 배경용**(검정 글자) | 나머지 모든 페이지 상단 | SVG |
| 심볼만 (글자 없이) | 파비콘, 카카오톡 공유 썸네일 | SVG |

- SVG로 주시는 게 중요합니다. 지금 PNG는 화면 크기가 커지면 흐릿해집니다.
- 글자는 **윤곽선(아웃라인) 변환**해서 주세요. 폰트 파일이 없어도 깨지지 않게요.
- AI 원본의 색이 위 '색' 표와 다르면, **원본 색을 그대로 두고** 저에게 알려주세요.
  로고 색을 바꿀지는 따로 판단할 문제라 임의로 맞추지 말아주세요.

### 1-2. 파비콘

브라우저 탭에 뜨는 작은 아이콘입니다. **심볼 SVG만 주시면 제가 뽑겠습니다** — 따로 안 만드셔도 됩니다.

### 1-3. 메인 첫 화면 영상 — 2가지 버전

메인 페이지를 열면 처음 보이는 **배경 영상**입니다.

| 버전 | 비율 | 길이 | 비고 |
|---|---|---|---|
| PC용 | 가로 16:9 (1920×1080) | 10~20초 반복 | 소리 없음 |
| 모바일용 | **세로 9:16 (1080×1920)** | 10~20초 반복 | 소리 없음 |

- PC 영상 하나만 만들어서 모바일에 쓰면 좌우가 잘려서 화면이 이상해집니다. **꼭 세로 버전을 따로** 주세요.
- 내용: 예배당 전경, 들어오는 사람들 뒷모습, 창으로 들어오는 빛, 찬양하는 손 — 얼굴 클로즈업은 피해주세요.
- 파일 크기는 각 5MB 이하로 부탁드립니다. (넘으면 제가 압축하겠습니다)
- **영상 촬영이 어려우면 정지 사진 2장**(가로 1장·세로 1장)으로 대체 가능합니다. 지금도 사진으로 버티고 있습니다.

## Phase 2 — 페이지별 대표 사진 (**9월 6일까지**)

각 페이지 맨 위에 크게 깔리는 사진입니다. **지금은 전부 무료 스톡 사진**이라 교회 사진으로 바꿔야 합니다.

| 페이지 | 필요한 사진 | 찍을(고를) 내용 |
|---|---|---|
| 교회소개 | 1장 | 교회 건물 외관 또는 예배당 전경 |
| 예배와 교육 | 1장 | 예배 중 전경 (뒤에서 찍은 회중석 + 강단) |
| 목양과 사역 | 1장 | 소그룹 모임 테이블, 나누는 손 |
| 교회 활동 | 1장 | 행사 현장 (식탁·플래카드·야외) |
| 새가족 | 1장 | 밝은 입구·열린 문·환영 데스크 |
| 교육 | 1장 | 교실·공부하는 책상 (얼굴 없이) |
| 사역 | 1장 | 봉사 현장 |

- 규격: 가로 2000px 이상 JPG. 가로로 넓게.
- 같은 날 같은 톤으로 찍으면 사이트 전체가 통일돼 보입니다. **한 번에 몰아서 촬영**하시는 걸 권합니다.

## Phase 3 — 기관·부서 활동사진 (촬영 1회 배치 · **9월 20일까지**)

각 기관 소개 칸에 들어가는 사진입니다. **기관당 4장**(대표 1 + 활동 3)이 기준입니다.

**목양** — 구역모임 · 전도회(남/여) · 집사회 · 권사회 · 동호회
**사역** — 별들의학교 · 제네바신학대학원 · 경향선교회 · 경향복지재단 · 경향학원 · 어린이집/놀이학원
**교육** — 주일학교 · 중고등부 · 대학부 · 청년회 · 경향시니어스쿨 · 평생교육원 · 새소식반

- 기관이 18곳이라 한 번에 다 못 찍습니다. **급한 순서: 목양 → 교육 → 사역**
- 사역 중 **경향복지재단·경향학원·어린이집**은 산하 기관이 여러 곳입니다
  (복지재단 3곳 · 학원 2곳 · 어린이집·놀이학원 3곳). 산하별로 사진이 따로 필요할 수 있는데
  아직 화면 구성이 안 정해졌습니다. **정해지면 알려드릴 테니 이 셋은 대표 사진 1장씩만** 먼저 부탁드립니다.
- 각 기관 담당 교역자께 "대표 사진 1장 + 활동 사진 3장"을 요청드리는 방식이 더 빠를 수도 있습니다.
  기존에 갖고 계신 사진이 있으면 그걸 골라 보정만 해주셔도 됩니다.
- ⚠️ **경향선교회 사진은 잠시 보류해주세요.** 보안지역에 계신 선교사님 얼굴·파송 국가가 노출되면 안 되는 문제가 있어
  선교회 담당자 확인 전까지는 사진을 받지 않겠습니다.

## Phase 4 — 아이콘 · 안내 그림 (9월 말 이후 · Phase 1~3 끝난 뒤)

1. **자주 찾는 메뉴 아이콘** — 메인 화면 가운데에 큰 아이콘 6~8개로 바로가기를 두는 안입니다.
   (넣을지 아직 안 정했습니다. 결정되면 요청드리겠습니다. 미리 의견 주셔도 좋습니다.)
2. **픽업 차량 노선 그림** — 5개 노선을 한눈에 보여주는 단순한 지도 일러스트.
3. **주차·시설 안내 아이콘** — 주차장, 엘리베이터, 유아실, 카페 등 픽토그램 세트.

## 함께 봐주셨으면 하는 것 (작업 아니고 의견)

1. **색 톤** — 지금 홈페이지 바탕색을 살짝 따뜻한 아이보리 쪽으로 잡아뒀습니다. 그대로 갈지, 더 하얗게 갈지 봐주세요.
2. **메뉴 펼침 방식** — 상단 메뉴에 마우스를 올리면 그 메뉴 하나만 펼쳐집니다(사랑의교회 방식). 지난번 합의한 대로 적용돼 있습니다.
3. **검색 기능** — 넣을지, 넣으면 무엇까지 찾게 할지(주보 PDF·설교 제목·페이지 글) 아직 미정입니다.
   참고할 만한 교회 사이트 보시면 알려주세요.

## 확인 방법

화면은 아직 제 컴퓨터에서만 돌아갑니다. **이번 주 안에 인터넷 주소로 올려서 링크를 보내드리겠습니다.**
링크를 받으시면 **휴대폰과 PC 양쪽에서** 한 번씩 봐주시고, 이상한 부분은 화면 캡처에 동그라미 쳐서 주시면 됩니다.
