# 경향교회 홈페이지 — 사진·영상 작업 목록

**홈페이지** https://ghpc-redesign-git-feature-ghpca-ghpc.vercel.app/
휴대폰·PC 양쪽 확인 필요. 이상한 부분은 화면 캡처 + 표시해서 카톡 전달.

현재 상태 — 메뉴 구조·화면 틀 완료. 사진 자리는 비어 있거나 임시 스톡 사진.
웹 관련 프로그램 불필요. 포토샵·프리미어 작업물 그대로 전달하면 홈페이지 반영은 이쪽에서 처리.

---

## 파일 전달 방법

**카톡 `+` → `파일`** 로 전달.

- ⚠️ `사진`·`앨범`으로 보내면 카톡이 화질을 자동 축소 → 큰 화면에서 흐릿하게 표시됨
- 메일 첨부도 가능 (원본 유지됨)
- 파일명 변경 불필요. `IMG_2847.jpg` 그대로 전달 + **용도만 한 줄 메모**
  예) "교회소개 대표 사진" / "구역모임 활동 3장"
- 3차부터 장수가 많아지면 전달 방법 재협의

## 사진 공통 기준

| 항목 | 기준 |
|---|---|
| 얼굴 | **식별 가능한 얼굴 제외.** 뒷모습·실루엣·손·측면·원거리 권장 |
| 어린이·청소년 | 얼굴 노출 시 보호자 동의 필수. 가급적 제외 |
| 톤 | 밝고 따뜻한 톤 (역광·햇살·나무·천 질감). 어둡고 차가운 톤은 메인 첫 화면 한정 |
| 구도 | 가로로 넓게. 인물 중앙 배치 시 잘림 발생 → 주변 여백 확보 |
| 장비 | 휴대폰 촬영 가능. 화질 충분 |
| 규격 | 가로 2000px 이상 JPG |

동의받은 사진은 얼굴 노출 가능. 해당 시 별도 표기.

## 1차 — 메인 배경 영상 2종 · **9월 20일까지**

홈페이지 접속 시 최초로 표시되는 전체 화면 배경 영상. 첫인상을 결정하는 화면.

| | 컴퓨터용 | 휴대폰용 |
|---|---|---|
| 크기 | 가로 1920 × 세로 1080 | 가로 1080 × 세로 1920 |
| 방향 | 가로 | **세로** |
| 길이 | 10~15초 | 10~15초 |
| 소리 | 없음 | 없음 |

**세로 버전이 별도로 필요한 이유** — 가로 영상을 휴대폰에 넣으면 좌우가 잘려 중앙만 확대됨.
인물이 반쯤 잘리거나 과하게 커짐. 같은 날 촬영분으로 가로·세로 각각 촬영이 효율적.

**장면** — 예배당 전경 / 입장하는 사람들 뒷모습 / 창으로 들어오는 빛 / 찬양하는 손
영상은 무한 반복 재생 → 시작과 끝 장면이 유사하면 이음새가 자연스러움.

**프리미어 내보내기 설정**

- `파일 → 내보내기 → 미디어`
- 형식 **`H.264`** (`.mp4` 생성)
- **오디오 체크 해제**
- 파일 크기 5MB 이하 권장. 초과 시 이쪽에서 압축 처리
- 크기 축소 필요 시 `비트레이트` 값 `3` 내외

**대체안** — 영상 제작이 부담될 경우 **정지 사진 2장**(가로 1 · 세로 1)으로 대체 가능.
현재도 사진으로 운영 중이라 진행에 지장 없음. 영상은 이후 여유 있을 때 교체 가능.

**로고 — 요청 없음.** 교회 자료실에 원본 파일 보유. 자체 처리 예정. 실패 시 별도 요청.

## 2차 — 페이지 대표 사진 7장 · **10월 18일까지**

각 페이지 상단에 전체 폭으로 깔리는 사진. 현재 전량 임시 스톡 사진.

| 페이지 | 내용 |
|---|---|
| 교회소개 | 교회 건물 외관 또는 예배당 전경 |
| 예배와 교육 | 예배 중 전경 (후방에서 촬영한 회중석 + 강단) |
| 목양과 사역 | 소그룹 모임 테이블, 나누는 손 |
| 교회 활동 | 행사 현장 (식탁 · 플래카드 · 야외) |
| 새가족 | 밝은 입구 · 열린 문 · 안내 데스크 |
| 교육 | 교실 · 책상 (얼굴 제외) |
| 사역 | 봉사 현장 |

**동일 날짜 일괄 촬영 권장.** 날씨·조명이 일치해야 사이트 전체가 한 세트로 보임.
분할 촬영 시 페이지마다 색감이 달라짐.

## 3차 — 기관 활동 사진 · **11월 22일까지**

기관 소개 칸에 들어가는 사진. **기관당 4장** (대표 1 + 활동 3) 기준.

| 그룹 | 기관 |
|---|---|
| 목양 (1순위) | 구역모임 · 전도회(남·여) · 집사회 · 권사회 · 동호회 |
| 교육 (2순위) | 주일학교 · 중고등부 · 대학부 · 청년회 · 경향시니어스쿨 · 평생교육원 · 새소식반 |
| 사역 (3순위) | 별들의학교 · 제네바신학대학원 · 경향복지재단 · 경향학원 · 어린이집/놀이학원 |

총 18곳. 일괄 촬영 불가하므로 위 순서대로 진행.

- **신규 촬영 불필요.** 각 기관 보유 사진을 수급해 선별·보정하는 방식이 더 빠름
- 담당 교역자에게 "대표 1장 + 활동 3장" 형태로 요청하는 경로도 가능
- ⚠️ **경향선교회 — 보류.** 보안지역 파송 선교사 얼굴·국가 노출 문제. 담당자 확인 후 별도 안내
- **경향복지재단 · 경향학원 · 어린이집** — 산하 기관 다수 (복지재단 3 · 학원 2 · 어린이집/놀이학원 3).
  화면 구성 미확정 → **대표 1장씩만** 우선 진행

## 4차 — 아이콘·그림 · 3차 이후 협의

1. **픽업 차량 노선 그림** — 5개 노선 표시 지도 일러스트
2. **안내 아이콘 세트** — 주차장 · 엘리베이터 · 유아실 · 카페 픽토그램
3. **자주 찾는 메뉴 아이콘** — 메인 화면 중앙 바로가기 6~8개. 도입 여부 미확정

## 의견 요청 (작업 아님)

1. **바탕색** — 현재 순백이 아닌 따뜻한 아이보리. 유지 / 더 밝게 중 판단
2. **메뉴 펼침** — 상단 메뉴 hover 시 해당 메뉴 하나만 펼쳐짐. 기존 합의안 적용 상태
3. **검색 기능** — 도입 여부 및 검색 범위(주보 · 설교 제목 · 페이지 본문) 미확정.
   참고할 교회 사이트 있으면 공유
